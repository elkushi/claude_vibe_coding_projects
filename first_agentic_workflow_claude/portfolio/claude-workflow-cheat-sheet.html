Claude Workflow Cheat Sheet

Build a repeatable, evidence-backed AI workflow in Claude Code from an empty folder: the loop, the phases, the prompts, the commands and the traps. Written from the competitor-analysis build (9 competitors, 192 sources, ~412 cited claims, validator-gated PDF).

WAT = Workflows · Agents · ToolsPlan → Build → Check → ApproveEvery claim cites a sourceSecrets only in .env

1The core idea in one picture

Why split the work

If each step is 90% reliable, five AI-only steps succeed 59% of the time. So the AI only decides; repeatable work runs as code; you approve at checkpoints.

  • Workflow: plain-language SOP: goal, inputs, tools, outputs, edge cases, lessons learned.
  • Agent: reads the SOP, runs tools in order, fixes failures, asks when unsure.
  • Tools: deterministic Python scripts (API calls, merges, validation, rendering).
  • Gate: a validator blocks the output if any rule is broken.

2The build algorithm, from zero

Rule of thumb: plan before code, design before research, validate before render, approve before the next phase.

6Evidence pipeline (how claims stay honest)

Evidence rules

  • Only cite pages actually opened
  • Self-claims labelled as claims
  • Inference labelled
  • "Not publicly disclosed"

Validator = errors

  • Schema mismatch
  • Missing source id
  • No URL / future date
  • 404, 410, DNS fail
  • TODO, example.com, banned names

Validator = warnings

  • 403 / 429 / SSL / timeout (bots)
  • Source > 90 days old
  • Unused sources
  • Competitor count off target

Cross-references

Analysis in base.json can cite "infobip:L1"; merge resolves it to the global S… id.

10Habits that made the difference

Plan before code

"Don't write code until I approve" keeps the build in order.

Questions in one batch

Answer once, up front, instead of being interrupted all build long.

Design before research

Approve a placeholder PDF so no research is wasted on layout churn.

Verify your own files

Old decks were wrong in places. Treat internal data as unverified.

Gate, don't trust

A validator that fails the build beats a promise to cite sources.

Parallel agents, one brief

Same written rules for every sub-agent gives comparable evidence.

Keep secrets out of chat

Put keys straight in .env; restrict each key to one API.

Mark what's internal

Tell Claude what must never appear in output (prices, partner names).
